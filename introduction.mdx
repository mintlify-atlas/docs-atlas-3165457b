## What is Autorma?

Autorma is a production-grade machine learning system that automatically classifies returned e-commerce items into five categories — **Casual Shoes**, **Handbags**, **Shirts**, **Tops**, and **Watches** — using computer vision.

Built on a fine-tuned EfficientNet-B0 model with **96.53% test accuracy**, Autorma provides a complete MLOps pipeline: from model versioning and batch inference to real-time monitoring and a user-friendly interface.

## Classification categories

Autorma classifies returned items into five categories:

- **Casual Shoes** — sports and casual footwear
- **Handbags** — purses, totes, and shoulder bags
- **Shirts** — button-up and formal shirts
- **Tops** — t-shirts, blouses, and casual tops
- **Watches** — wristwatches and timepieces
